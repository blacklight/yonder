# Contributing to Yonder

First of all, thanks for consider contributing to this project!

The guidelines are simple.

## Repository

Yonder has two repositories:

- The one on my personal Forgejo instance is
  [git.platypush.tech/blacklight/yonder](https://git.platypush.tech/blacklight/yonder)
  or [git.fabiomanganiello.com/yonder](https://git.fabiomanganiello.com/yonder) if you
  prefer a shortcut.
- The Github mirror is
  [github.com/blacklight/yonder](https://github.com/blacklight/yonder) - it's a
  pull-only mirror from my Forgejo instance.

## Issues

If you find an issue in the project, send it to the `<repo_url>/issues`.

I prefer the Forgejo instance, but Github should also be fine (but it may just
be a bit less monitored).

Provide an exhaustive description of the problem, preferably with replication
steps, screenshots, logs or stack trace attached.

## Code contributions

Same as the above.

Fork the repo either from Forgejo or from Github, and open a PR (preferably on
Forgejo).
